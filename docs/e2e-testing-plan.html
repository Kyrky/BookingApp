Priority 1 — Critical Flows

Search & Filter Properties

  • Text search by title/address
  • Price range filters (min/max)
  • Sorting options (date, name, price)
  • Clear filters button

Booking Date Validation

  • Overlapping bookings detection
  • Past dates blocked
  • Check-out before check-in validation
  • Proper error messages

Toast Notifications

  • Success messages
  • Error notifications
  • Auto-dismiss after 3 seconds
  • Manual close button

Role-based Access Control

  • Admin vs User permissions
  • Property ownership checks
  • Protected route redirects

Priority 2 — Negative Scenarios

Access Without Authentication

  • Protected routes redirect to login
  • API returns 401

Editing Others' Property

  • Non-owner gets error
  • Admin can edit any

Invalid Form Data

  • Required field validation
  • Format validation (email, numbers)
  • Visual error indicators

Technical Recommendations

Page Object Model (POM)

Create reusable page objects for Auth, Properties, Bookings pages to reduce duplication and improve maintainability.

Test Fixtures

Create shared fixtures for test users (admin, regular user) and test data (properties, bookings).

API Mocking

Consider MSW for faster, more stable tests by mocking API responses.
