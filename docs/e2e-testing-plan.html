🛠️ Technical Recommendations

  • Page Object Model (POM)

    Create reusable page objects for Auth, Properties, Bookings pages to reduce duplication and improve maintainability.

  • Test Fixtures

    Create shared fixtures for test users (admin, regular user) and test data (properties, bookings).

  • API Mocking (Optional)

    Consider MSW for faster, more stable tests by mocking API responses.
